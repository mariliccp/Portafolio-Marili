# Marili Cervantes — Portfolio Website

A responsive static portfolio built with HTML, CSS, and JavaScript. It is ready to deploy with GitHub Pages.

## Files
- `index.html` — site content and structure
- `styles.css` — layout, colors, typography, responsive design
- `script.js` — mobile navigation and scroll animations
- `assets/Marili_Cervantes_Resume.docx` — downloadable résumé

## Customize before publishing
1. Replace the green profile-photo placeholder in `index.html` with your own image.
2. Add your photo to `assets/`, for example `assets/profile.jpg`.
3. Replace this block:
   `<div class="portrait-placeholder">...</div>`
   with:
   `<img class="portrait-placeholder" src="assets/profile.jpg" alt="Marili Cervantes">`
4. Add project photos/screenshots to the project cards if desired.
5. Update any résumé details whenever your experience changes.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `marili-portfolio`.
2. Upload all files in this folder to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)` folder, then save.
7. GitHub will provide the public website URL after deployment.

## Optional custom domain
If you purchase a domain later, you can connect it from **Settings → Pages → Custom domain**.
